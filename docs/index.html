macOS security warning on first launch?

This app is open-source and not signed with an Apple Developer certificate ($99/yr). macOS will show a warning on first launch. To open:

System Settings → Privacy & Security → scroll down → "Open Anyway"

Or right-click the app → Open → click Open.

Real-time tracking

Refreshes every 60 seconds via a metadata endpoint. No model tokens consumed.

Two usage windows

5-hour session limit and 7-day rolling limit, always visible.

Color-coded bars

Green, yellow, red — know at a glance when you're running low.

Zero-login setup

Reuses the OAuth credentials already on your Mac from the Claude Code CLI.
